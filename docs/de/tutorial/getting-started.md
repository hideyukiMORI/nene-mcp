# Erste Schritte

nene-mcp ergänzt **stdio MCP** für HTTP-APIs mit NENE2-kompatiblem Katalog.

## Voraussetzungen

- PHP **8.2+**, [Composer](https://getcomposer.org/), MCP-Host (Cursor, …)

## Installation

```bash
composer require hideyukimori/nene-mcp:^0.1
```

Aktuellen Tag auf [Packagist](https://packagist.org/packages/hideyukimori/nene-mcp) prüfen. Wenn die Docs neuer sind als Packagist, den **veröffentlichten** Tag verwenden.
