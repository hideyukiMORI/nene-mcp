# Premiers pas

nene-mcp ajoute **stdio MCP** à toute API HTTP via un catalogue compatible NENE2.

## Installation

```bash
composer require hideyukimori/nene-mcp
```

PHP 8.2+, Composer, hôte MCP (Cursor, Claude Desktop).
